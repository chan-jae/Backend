<book>
책 제목: {bookTitle}
글쓴이: {author}
출판사: {publisher}
도서 레벨: {level} (도서난이도 {difficulty})
</book>

아래는 현재 활동지 전체 JSON입니다. 각 문제는 id로 구분합니다.
<sheet>
{sheet}
</sheet>

새로 만들 문제 id: {ids}

## 새로 만드는 방법
- id가 위 목록에 있는 문제만 새로 만드세요. 목록에 없는 문제는 글자 하나도 바꾸지 말고 그대로 두세요.
- 새 문제는 원래 문제와 같은 영역, 같은 자리에 들어갑니다. id 값과 키, 보기 개수는 그대로 두고 내용만 바꾸세요.
- 원래 문제와 다른 내용을 물어보세요. 질문 표현만 살짝 바꾸거나 보기 순서만 섞은 문제는 안 됩니다.
- 새 문제는 그대로 남는 다른 문제와 같은 내용을 묻거나 겹치면 안 됩니다. 새로 만드는 문제끼리도 겹치지 않게 하세요.
- 정답이 드러나지 않게 하세요.
  - 새 문제의 문장, 질문, 보기에 남는 문제의 정답이 드러나면 안 됩니다.
  - 남는 문제의 문장, 질문, 보기, 정답(exampleAnswer 포함)을 보고 새 문제의 정답을 알 수 있어도 안 됩니다.
- 정답 번호는 남는 문제까지 합친 전체에서 한 번호에 몰리지 않게 정하세요.
- factual, factualShortAnswer는 배열 앞쪽 문제일수록 쉽고 책의 핵심 내용을 묻는다는 규칙을 새 문제에도 지키세요.

## 응답
- 새로 만든 문제를 넣은 활동지 전체 JSON 하나만 응답하세요. 위 JSON과 키, 배열 개수, 순서가 똑같아야 합니다.
